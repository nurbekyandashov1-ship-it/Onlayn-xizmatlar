## 🌐 Saytni GitHub Pages Orqali Internetga Joylash Qadamlari

Saytingiz internetda barcha uchun ochilishi uchun quyidagi oddiy qadamlarni bajaring:

### 1-usul: GitHub Veb-sayti orqali (Eng osoni)
1. Brauzeringizda **[GitHub.com](https://github.com/)** ga kiring va o‘z profilingizga kiring.
2. Yuqori o‘ng burchakdagi **"+"** tugmasini bosing va **"New repository"** ni tanlang.
3. Repository name maydoniga masalan: `nurbek-digital` deb yozing.
4. Repozitoriyani **Public** qiling va **"Create repository"** tugmasini bosing.
5. Yangi sahifada **"uploading an existing file"** havolasini bosing.
6. Loyihangizdagi barcha fayllarni (`index.html`, `style.css`, `script.js`, `robots.txt`, `sitemap.xml`, `README.md`) sudrab olib kelib tashlang (drag & drop).
7. Sahifaning pastidagi **"Commit changes"** tugmasini bosing.
8. Repozitoriyangizning **Settings** (Sozlamalar) bo‘limiga kiring.
9. Chap tomondagi menyudan **"Pages"** bandini bosing.
10. **Build and deployment -> Branch** bo‘limida `None` o‘rniga `main` (yoki `master`) ni tanlang va **Save** tugmasini bosing.
11. 1-2 daqiqa kuting, GitHub sizga rasmiy sayt havolasini beradi:
    👉 `https://nurbekyandashov1-ship-it.github.io/nurbek-digital/`

### 2-usul: Git buyruqlari orqali (Terminalda)
Agar kompyuteringizda Git o‘rnatilgan bo‘lsa:
```bash
git init
git add .
git commit -m "NURBEK DIGITAL sayti dastlabki versiyasi"
git branch -M main
git remote add origin https://github.com/nurbekyandashov1-ship-it/nurbek-digital.git
git push -u origin main
```
So‘ngra GitHub Settings -> Pages bo‘limidan `main` branchini faollashtiring.
